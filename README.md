# Bokuyaba Downloader Discord Bot

A Discord bot that downloads and unscrambles images from Championcross comic viewer URLs, then posts it in a thread under the raw-dumps channel


## Installation

1. **Clone or download this project**
   ```bash
   cd bokuyabadownloader-bot
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```


## Usage

1. **Start the bot**
   ```bash
   node bot.js
   ```

2. **Use the slash command in Discord**
   ```
   /downloadyabachapter url:https://championcross.jp/viewer/...
   ```
